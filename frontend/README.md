# Online Shop — Frontend

Фронтенд интернет-магазина на React + Vite + TypeScript.
Работает поверх REST API бэкенда (Node/Express + PostgreSQL).

🔗 **[Смотреть сайт](https://lika380.github.io/shop-beauty/)**

## Стек

- React 19 + TypeScript
- Vite
- React Router v7
- Обычный CSS с переменными (светлая/тёмная тема)
- `fetch` напрямую, без axios/react-query

## Запуск локально

```bash
npm install
cp .env.example .env
npm run dev
```

Откроется на `http://localhost:5173`.

В `.env` укажите адрес backend:
```
VITE_API_URL=http://localhost:3000
```

## Что умеет

**Покупатель:** каталог с поиском/фильтром/сортировкой, карточка товара, корзина, оформление заказа, история своих заказов.

**Админ:** CRUD товаров, создание категорий, просмотр всех заказов и смена статуса.

Доступ к разделам проверяется и на фронте (скрытие недоступных страниц), и на бэкенде (реальная защита).

## Структура

```
src/
  api/         — запросы к backend (auth, products, cart, orders...)
  context/     — авторизация и корзина (глобальное состояние)
  components/  — переиспользуемые UI-блоки
  pages/       — страницы (каталог, корзина, заказы, админка)
  utils/       — форматирование цен, статусов заказа
```

## Особенности API, которые важно знать

- Списки приходят в формате `{ data: [...], pagination: {...} }`
- Цены иногда приходят строкой (особенность Postgres) — форматируются через `utils/format.ts`
- Ошибки всегда в формате `{ error: { message, code } }`
